# AI MiniMap

作者 / Author: wwj

This folder is the dependency-free browser extension source.

- Chrome / Edge: load this folder from the browser's extension manager in Developer Mode.
- Safari 27: add this folder as a temporary extension in Safari's Developer settings.
- Firefox: run `python3 script/package.py` from the repository root; load the generated Firefox manifest through `about:debugging`.

Read the [English documentation](https://github.com/CaryK753/AI-MiniMap#readme) or [中文文档](https://github.com/CaryK753/AI-MiniMap/blob/main/README.zh-CN.md) for features, screenshots and limitations.
